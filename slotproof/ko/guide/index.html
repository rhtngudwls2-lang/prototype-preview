인쇄용 PDF QR 검수 방법

실제로 인쇄에 보낼 최종 PDF를 준비하세요. 승인 위치는 인쇄 PDF와 독립적으로 만든 CSV를 사용하세요. 값만 나열한 목록으로는 위치를 증명할 수 없습니다.

1. 승인 CSV 준비

UTF-8 CSV에 page,row,column,value,kind 헤더를 사용합니다. 페이지·행·열은 1부터 시작합니다. 보이는 PDF 기준 맨 위가 첫 행, 왼쪽이 첫 열입니다. 앞자리 0, 여백 문자, 대소문자를 유지합니다. CSV 행 순서는 무관하고 다른 위치에 같은 값이 반복돼도 됩니다.

2. 보이는 배치 확인

두 파일을 선택하고 행, 열, 여백을 입력합니다. 각 PDF 페이지를 미리 보고 격자를 확인하세요. 같은 크기의 셀을 전제로 합니다. PDF의 보이는 잘림 범위와 회전을 반영하며, 같은 작업 내 페이지 크기나 잘림 범위가 다르면 통과 처리하지 않습니다.

3. 검사 결과 읽기

불일치는 읽힌 값이 다를 때, 누락은 기댓값 위치에 보이는 잉크가 없거나 페이지 자체가 없을 때, 추가는 승인되지 않은 QR을 읽었을 때입니다. 확인 필요는 통과가 아닙니다. 승인 빈칸은 kind가 blank이고 값이 비어야 합니다. 완전히 빈 구분 페이지는 kind를 separator로 지정하고 행·열·값을 비워 두세요. 장식이 있는 빈칸이나 구분 페이지는 직접 확인이 필요합니다. QR 옆에 분류하지 못한 잉크가 남으면 확인 필요로 분류합니다. 검수할 영역은 흰 바탕에 QR만 두세요. 로고, 도장, 재단 표시가 있으면 직접 확인이 필요할 수 있습니다. 선언되지 않은 위치는 통과하지 않습니다.

지원 범위

숫자·영숫자·UTF-8 일반 텍스트를 담은 일반 QR을 지원합니다. GS1, Micro QR, 구조화 연결, 바이너리, 색상·실제 인쇄 품질 등급, 불규칙 배치는 지원하지 않습니다. 최대 PDF 40MiB, CSV 4MiB, 80페이지, 600 위치, 각 16행·16열입니다. 심하게 손상됐거나 작거나 배치가 다른 QR은 직접 확인하세요. 결과 CSV는 앞자리 0을 보존하고 수식 실행을 막기 위해 QR 값을 JSON 문자열 형태로 저장합니다.
