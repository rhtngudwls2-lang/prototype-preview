# BatchQuote | 로컬 견적 요청 초안 / Local request worksheet

## 한국어
이 폴더의 index.html을 브라우저에서 엽니다. 계정, 서버, npm 설치나 인터넷이 필요하지 않습니다. 화면의 한국어/EN으로 언어를 바꿀 수 있습니다.
1. 품목, 정수 수량, 수령 방식, 희망 날짜, 현지 시각, 원화 예산, 포장 형태를 입력합니다.
2. 요청서 만들기를 눌러 미리보고, 운영자 화면에서 확인할 항목을 살핍니다.
3. 필요한 경우에만 초안 복사를 눌러 사용자가 직접 활용합니다. 복사가 지원되지 않을 경우 선택 가능한 텍스트가 나타납니다. 초안은 이 탭에만 있으며 새로 고침하면 지워집니다.

예시: 임의의 수량 12, 정수 예산 60,000원, 향후 날짜와 입력란에 있는 시간을 사용해 화면만 확인하세요. 실제 주문, 견적 확정, 음식 제공 가능성, 포장·배송료, 결제, 발송, 계정 또는 외부 전송을 제공하지 않습니다. 식품 관련 조건과 가격은 서비스를 제공하는 곳에 직접 확인하세요. 실제 개인 연락처는 입력하지 마세요.

## English
Open index.html directly in a modern desktop browser. No account, server, npm install or network connection is required. Choose Korean or EN in the top navigation.
1. Enter the product type, whole quantity, fulfillment preference, desired date and local time, a whole KRW budget, and packing preference.
2. Create the request draft, then use Operator view to review questions for the service provider.
3. Copy only if you choose. If clipboard access is unavailable, the app displays selectable text. Refreshing clears the tab draft.

For a synthetic check, try a quantity of 12, budget of 60,000 KRW and a listed time on a future date. This is an unconfirmed worksheet only. It does not accept, pay for, send, or fulfill any order. Price, availability, ingredients, packaging, delivery and all fees must be independently confirmed; do not enter personal contact details.

Private local distribution candidate; no hosted service, account, or publication is included.
